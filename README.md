# Secure Your Own Wi-Fi Network

This project is a Wi-Fi security assessment conducted using tools like **Nmap**, **Wireshark**, and password best practices.

## ?? Tools Used
- Nmap (Port scanning and network enumeration)
- Wireshark (Traffic analysis)
- Windows settings (SMB hardening)
- Strong password evaluation

## ?? Deliverables
- Full report: Wi-Fi_Security_Assessment_Report.docx
- Key findings: Open ports, connected devices, traffic types, password strength evaluation

## ?? Recommendations
- Close unused ports (e.g., SMB)
- Use long, complex passwords for hotspot
- Regularly audit connected devices
- Use VPN on public networks

## ?? Limitations
Aircrack-ng testing was skipped due to lack of USB Wi-Fi adapter with monitor mode.
